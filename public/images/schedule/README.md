# /public/images/schedule

Add a detailed schedule graphic per day here — e.g. `day1.jpg`, `day2.jpg` —
then uncomment/set the matching `image` line in `data/schedule.ts`:

    image: "/images/schedule/day1.jpg",

Once set, the Schedule page automatically shows the image instead of the
"detailed timing to be announced" placeholder for that day. No other code
changes needed.

Recommended: whatever aspect ratio the graphic naturally is — the page
displays it at full width, so a landscape timetable image works best.
