# /public/images/speakers

Add speaker headshots here using the filenames already referenced in
`data/speakers.ts` (e.g. `tim-miller.jpg`). If a file is missing, the
Speakers page automatically falls back to a set of initials on a navy
circle — nothing breaks, it just looks plainer until a real photo is added.

Recommended: square photos, at least 400x400px, .jpg or .webp.
