# /public/images/places

Add a photo per place here using the filenames already referenced in
`data/places.ts` (e.g. `qila-mubarak.jpg`). Until a file is added, the
Places to Visit page shows a clean text-only card — nothing breaks.

Recommended: landscape orientation, ~1200x800px, .jpg or .webp, credit the
photographer in this file if using a Creative Commons image (e.g. from
Wikimedia Commons).
