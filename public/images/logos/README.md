# /public/images/logos

Real logo files, provided directly by you and converted to `.svg` (each is
the original raster image — PNG/JPG/WebP/ICO — embedded inside an SVG
wrapper, so the file extension is consistent across all logos without any
quality loss from vector tracing).

- tiet.svg — Thapar Institute of Engineering & Technology
- trs.svg — The Robotics Society (TRS)
- coe-dsai.svg — Centre of Excellence, Data Science & AI
- mathworks.svg, qualisys.svg, noraxon.svg, delsys.svg, nugenix.svg,
  labellerr.svg — exhibitor logos, shown on the Exhibitions page

To replace any of these later, just overwrite the same filename with a new
file (any image format works — re-run the same PNG-in-SVG wrapper approach,
or swap in a real vector `.svg` if you get one from the company directly).
