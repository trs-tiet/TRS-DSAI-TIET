# /public/images/logos

These SVGs are **typographic placeholders**, not the companies' actual
trademarked logos. I didn't scrape or reproduce real brand logos here on
purpose — using another company's trademarked logo file without a
verified license/brand-kit permission is a genuine legal grey area, even
for a legitimate partner-attribution use like this.

The compliant way to get real ones:
- Most companies publish official brand assets on a "media kit," "press,"
  or "brand guidelines" page — check the footer of mathworks.com,
  qualisys.com, noraxon.com, delsys.com, and labellerr.ai for one.
- Or ask your contact at each exhibitor to send their logo file directly
  (this is completely standard for event/conference partner listings).

Once you have real files, drop them in here with the same filenames (or
update the `logo` path in `data/exhibitors.ts`) — same for the TIET / TRS /
COE|DSAI institutional logos.

Files here:
- tiet.svg, trs.svg, coe-dsai.svg — institutional logos
- mathworks.svg, qualisys.svg, noraxon.svg, delsys.svg, nugenix.svg,
  labellerr.svg — exhibitor logos, shown on the Exhibitions page
